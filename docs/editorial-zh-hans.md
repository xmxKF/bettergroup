## content/zh-hans/index.json（4 处）

理由：清除「据点／实务／上列」等台港用语，并与其他页面已有的措辞取齐。

| 位置 | 修改前 | 修改后 |
|---|---|---|
| `hero.sub` | 以香港为**据点**，连接日系主力设备品牌…… | 以香港为**基地**，连接日系主力设备品牌…… |
| `pillars.entries[3].text` | 针对设备操作、维护保养与工艺**实务**规划培训内容 | 针对设备操作、维护保养与工艺**实操**规划培训内容 |
| `processes.brand_note` | **上列**品牌设备由倍特尔提供采购…… | **上述**品牌设备由倍特尔提供采购…… |
| `ai.paragraphs[0]` | 对标到九大工艺段的实际**使用**场景 | 对标到九大工艺段的实际**应用**场景 |

- 「据点」是日源／台港说法，大陆企业文案用「基地／所在地」（术语表 §12：营运据点→运营基地）。
- 「实务」→「实操」，与术语表 §12「实务课程→实操课程」及 `services.json` 已有的「实操课程」一致。
- 「上列」→「上述」，与 `services.json`、`contact.json` 中已使用的「上述」统一。
- 「实际应用场景」是大陆产业标准搭配，`about.json` 已用此说法。

## content/zh-hans/equipment.json（3 处）

理由：两处台港用语，一处不符合汉语搭配习惯的直译标签。

| 位置 | 修改前 | 修改后 |
|---|---|---|
| `banner_label` | 设备列照片 | 成排设备照片 |
| `flow.title` | 工艺如何**串接** | 工艺如何**衔接** |
| `processes.brand_note` | **上列**品牌设备…… | **上述**品牌设备…… |

- 「设备列」是母本「設備列」的逐字沿用，汉语不成词；改为「成排设备照片」（对应
  英文版 “Equipment row photo”）。该串为 `aria-label`，不影响版面。
- 「串接」是台港说法，大陆工艺语境用「衔接」（工序衔接）。

## content/zh-hans/services.json（3 处）

理由：一处语义重复，两处台港用语。

| 位置 | 修改前 | 修改后 |
|---|---|---|
| `services[0].features[3]` | 备件、耗材与维护计划**规划** | 备件、耗材与维护计划**制定** |
| `services[0].steps[3].text` | **出机**前查验与交付文件整理。 | **发货**前查验与交付文件整理。 |
| `flow.steps[2].text` | 执行商务条件，**出机**前完成状态查验与文件确认。 | 执行商务条件，**发货**前完成状态查验与文件确认。 |

- 「计划规划」两词同义叠用，改为「计划制定」。
- 「出机」为台港设备业说法，大陆对应「发货／出货」；此处指交付前查验，用「发货前」。
