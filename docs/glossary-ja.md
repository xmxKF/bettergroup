# glossary-ja.md — 日本語版 用語集（zh-Hant → 日本語）

`content/ja/*.json` の訳語基準。第 3 フェーズで残り 14 ページを訳す担当者は、
**必ずこの表の訳語をそのまま使う**こと（新語を作らない）。

原則
1. 文体は **敬体（です・ます調）**、半導体業界のビジネス文書レジスター。
2. 句読点は全角「、。」、括弧は全角「（）」、中黒「・」、代替スラッシュは全角「／」。
3. **ラテン文字・数字の前後には半角スペースを 1 つ入れる**（例：`9 大プロセス`、`AI 統合`、`CMP（化学機械研磨）`）。
   例外：`AI` が語頭に来て直後が助詞の場合も同様にスペースを入れる（`AI と先端製造の統合`）。
4. ブランド名・アーキテクチャ名・年号・数値・URL・メールアドレスは**翻訳しない**（原文のまま）。
5. eyebrow ラベル（`WHAT WE DO`、`NINE PROCESS AREAS` など）は**英語のまま・すべて大文字**（デザイン要素）。
6. AI の定量結果は必ず「第三者が公開した**ベンチマーク**（対標）であり、BETTER 自身の測定値ではない」と読める表現にする。

### 11.3 表記ルール（ラテン文字・数字まわり）

1. 増減を表す符号の前に半角スペースを 1 つ入れる：`学習 -62×`、`流出率 -15%`、
   `バックトラック -55.06%`、`テスト時間 -25%`。
2. 不等号の前にも半角スペース：`1 クラス <15 枚`、`MAE <15×10⁻⁵V`、`精度 >90%`。
3. 概数の `~` は使わない。文中は **`約 92%`**、範囲は全角波ダッシュ **`-20〜25%`**。
4. 全角セミコロン `；` は使わない。並列は全角スラッシュ **`／`**。
5. 全角プラス `＋` の前後にスペースを入れない：`RNN 時系列 FDC＋連合学習`。
6. 「ベンチマーク指標：」のあとにコロンを重ねない（`…：Blackwell 量産：テスト時間 -25%` は不可 →
   `…：Blackwell 量産でテスト時間 -25%`）。
7. 定量結果には主語を補う：`予測精度 約 92%`、`精度 >90%`（数値だけを置かない）。

アートディレクション用語（クールトーン／寒色調、余白を活かした構図、左右対称の構図、

|---|---|

### 11.9 `title_lat` のスラッシュ

言語不変フィールド `title_lat` は ASCII の `/` を前後スペース付きで使う：**`LithoDreamer / ILT`**。
訳文側（`arch` など、言語不変ではないフィールド）の日本語文中では全角の `／` のままでよい。
